# זה או זה · רוק ומטאל

משחק בחירות אינסופי: להקה מול להקה, אלבום מול אלבום, שיר מול שיר.

- הנתונים נשלפים בזמן אמת מ-[MusicBrainz](https://musicbrainz.org).
- הפריטים מסוננים לפי פופולריות ב-[ListenBrainz](https://listenbrainz.org).
- אין שרת ואין ספריות: רק `index.html`, `css/` ו-`js/`.

## בדיקות

צריך Node 22. אין תלויות להתקנה.

```bash
npm test
```

בדיקות הקצה-לקצה רצות בדפדפן Chromium דרך Playwright. MusicBrainz ו-ListenBrainz מדומים בהן מתוך `tests/fixtures/`:

```bash
npm run e2e
```

## העלאה ל-GitHub Pages

1. מעלים את התיקייה למאגר ב-GitHub.
2. ב-Settings, בוחרים Pages.
3. תחת Build and deployment, בוחרים Deploy from a branch.
4. בוחרים את הענף `main` ואת התיקייה `/ (root)`.
5. אחרי כדקה האתר זמין בכתובת שמופיעה שם.

## בדיקה ראשונה בדפדפן אמיתי

הבדיקות האוטומטיות רצות מול נתונים מדומים. מול השרתים האמיתיים האתר עוד לא נבדק, ולכן הבדיקה הראשונה צריכה להיות בדפדפן:

1. פותחים את האתר ואת ה-Console. במחשב: F12, ואז Console.
2. אם מופיעה ההודעה "לא הצלחנו להביא שאלה", מעתיקים את השורה `Could not load a question` מה-Console.
3. משחקים כ-20 שאלות, ושמים לב:
   - אילו להקות, אלבומים או שירים לא מוכרים.
   - כמה זמן מחכים בין שאלה לשאלה.
